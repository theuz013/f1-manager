# F1 Manager

Jogo de gerenciamento de equipe de Fórmula 1 — PWA instalável no celular.

## Como jogar
Acesse o link e instale como app:
- **Android**: Chrome → menu ⋮ → "Adicionar à tela inicial"
- **iOS**: Safari → compartilhar → "Adicionar à Tela de Início"

## Stack
- React 18 (bundled)
- PWA com manifest + IndexedDB para persistência
- Hospedado via GitHub Pages
